# SPMP-OS Stage 23 — SNES HiRes video / GBA cartridge preflight

**Дата:** 2026-11-11. **Статус:** интегрировано в компьютерный прототип, два компонента скомпилированы под ARMv5. Не устанавливаемая прошивка.

## Изменения

1. `include/spmp_small_video.h`, `src/platform/spmp_small_video.c`: переносимый C-скейлер LCD 320x240, nearest-neighbor, сохранение пропорций, вход RGB565, 0RGB1555, XRGB8888. Строковый шаг источника проверяется. Нет heap в преобразователе. Смена разрешения при SNES HiRes выделяет только выходной буфер, не буфер полного HiRes-кадра.
2. `src/cores/libretro_multi_adapter.c`: SNES и PicoDrive используют преобразователь до выделения framebuffer. Видеопроцессор эмулятора по-прежнему рассчитывает исходный кадр; оптимизированы только кадр вывода/его потребление RAM и передача HAL. Нельзя обещать рост FPS самого ядра.
3. `include/spmp_gba_cart.h`, `src/cores/gba_cart.c`: проверка первых 0xC0 байт заголовка GBA, логотипного префикса, фиксированного значения и комплементарной контрольной суммы. **Это НЕ эмулятор GBA**. Неисполняемые/повреждённые ROM можно отвергать до запуска будущего ядра. Для строжайшей проверки Nintendo logo надо добавить проверку всех 156 байт.
4. Makefile: `make stage23-check` / `make stage23-arm`.

## RAM только видеобуфера

- SNES HiRes 512x448 RGB565: раньше 458752 байт (448 КиБ) в адаптере; теперь fit 274x240 = 131520 байт (~128,4 КиБ).
- Обычный SNES 256x224 остаётся 256x224 = 114688 байт.
- Это **не** изменение внутреннего буфера PPU и не общий расход памяти Snes9x.

## Проверки в текущей рабочей папке

- `make stage23-check`: два C-теста, два ARMv5 ELF32/EABI5 объекта — успешно.
- `make host`: компьютерный SPMP-OS пересобран с новым конвертером — успешно.
- `./build/spmp-os-host --run-core snes --content samples/snes_stage18_smoke.sfc --frames 4`: 4 кадра.
- `python3 -m unittest discover -s tests -v`: 69/69 существующих тестов пройдены.
- ARMv5-код **не запускался на Defender**.

## Что осталось до GBA и SNES на настоящем железе

- Для GBA нужен исходный gpSP с интерпретатором ARM7TDMI или адаптацией ARMv5 JIT. Сам по себе логотип/контрольная сумма не дают запуск игр. В доступных локальных архивах только заводские GBA бинарники. Открытый upstream: https://github.com/libretro/gpsp — заявлены JIT ARMv6/7 и интерпретатор для иных архитектур.
- Для SNES нужен ARMv5-совместимый облегчённый Snes9x 2005/2002 либо измерение современных Snes9x на реальном H/W. В Stage 23 оптимизирован только путь видео из libretro в HAL.
- Нужны проверенный RedBoot RAM boot, MMIO/LCD/audio/SD HAL и фактический бюджет RAM. Оригинальная FSP/RedBoot не менялись.

Коммерческие ROM и BIOS в пакете отсутствуют. Сторонние исходники сохраняют оригинальные лицензии. Экспериментальный PSX4ALL и весь PicoDrive MD/CD/32X из Stage 22 сохранены.
