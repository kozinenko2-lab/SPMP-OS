# Семь пользовательских бинарных модулей: подтверждённые наблюдения

| Порт | Сигнатура | Примеры внешних данных | Вывод |
|---|---|---|---|
| Doom r3 | NGame1.0 | doom.wad, doom2.wad, /fat20a | Пример игрового runtime и файловой системы |
| Quake beta1 | NGame1.0 | config.cfg, /fat20a | Графика и рендеринг, конфиг, сохранения |
| MSX r36 | NGame1.0 | /fat20a, ROM-данные | Эмулятор, переназначение клавиш |
| SMS r1 | NGame1.0 | smsgg.cfg, /fat20a | 8-битные консоли и настройки |
| z26 | NGame1.0 | данных недостаточно | Atari 2600, формат подтверждён |
| ScummVM 1.6.0git | NGame1.0 | /fat20a, /Rom/IMAGE/GAME/SPDF.BIN | Комплексный файловый/видео/аудио backend |
| SWFPLAYER 61 492 | без NGame1.0 | SSL_PlayNext, SSL_SaveSSLData | Другой ARM-модуль, вероятно API Flash-плеера |

Пути `/fat20a`, `/Rom/IMAGE/GAME/SPDF.BIN` и данные игр не доказывают, что все модули работают на конкретной Defender. Во всех отчётах используются только чтение байтов, сигнатуры, строки и хеши; файлы не запускались и не были изменены. Документация SPMP8000 описывает runtime `NGame1.0`; возможные упаковка/шифрование требуют формального разбора заголовка и теста на ПК.
