# SPMP-OS Stage 16 — Emulator Settings / SMS Plus GX

**Статус: демонстрационный runtime на ПК и перемещаемые ARMv5-объекты. Это НЕ прошивка для установки на Defender MultiMix Magic.** Штатные RedBoot, FSP и NAND не изменялись.

## Новое в Stage 16

### Единый пункт Settings

Во всех уже подключённых ядрах системное меню содержит 6 пунктов: **Continue, Save State, Load State, Select Slot (1–5), Settings, Exit Game**. Меню открывается событием короткого Power (30–650 мс), но **реальный аппаратный код Power в Defender ещё не установлен**. Подтверждать его на физической плате обязательно; состояние кнопки в хост-тестах имитируется.

- Settings по каждому ядру отдельно: `settings/<core>-<hash>.cfg`, версия, FNV-32 контроль целостности, проверка диапазонов и откат при ошибке записи.
- Общие: масштабирование `Native/Fit/Full` (отложено до LCD-композитора), громкость 0–10 (**сейчас применена к PCM**), `Swap A/B` (**сейчас применена к input router**), пропуск кадров (отложено до планировщика).
- Специальные: GB-палитра/точность, NES sprite limit/регион, SMS регион/бордюр Game Gear, PAL/NTSC для некоторых платформ, модель ZX, GBA BIOS, настройки PS1 и др. **Пока записываются в конфигурацию, но применяются только если адаптер ядра и драйвер поддерживают конкретную опцию**. Не выдавать это за работающую функцию ядра.
- Старое меню состояний сохранено: пять слотов, скриншот чистого игрового кадра 120×90 RGB565, быстрый предпросмотр без чтения игрового состояния. У SMS **сохранения состояния отключены**, пока исходный формат с указателями не заменён безопасным переносимым сериализатором. Персистентная SRAM поддерживается через callback, если драйвер предоставляет его.

### Добавлен реальный SMSPlusGX (Master System / Game Gear)

Из загруженного пользователем `retro-go-stm32-…zip` выделены оригинальные исходники ядра SMS Plus GX — Z80, SMS/GG, VDP, PSG/SN76489. Не надо путать это с ARMv5-портом для конкретной платы:

- Linux/ПК: независимый `third_party/smsplus/libsms_spmp.so`, загружается из реестра динамически и сохраняется в памяти между ROM `.sms` и `.gg`. Старый TGEmu имеет пересекающиеся имена глобальных переменных, поэтому два ядра изолированы разными ELF-модулями.
- Запуск тестового Z80-кода: `LD A,0x5A; LD (0xC000),A; JR -2`, RAM проверена; кадры 256×192 (SMS) / 160×144 (GG) и стереозвук 32 кГц.
- Точечные исправления: типы `uint32`/`int32` заменены на строго 32-битные; убран float-множитель усиления аудио, исправлены сдвиги знаковых типов при построении VDP-таблицы; исправлено **неопределённое поведение** в `ARG16` Z80 (два неупорядоченных инкремента PC), найденное при проверке UBSan; структурное выравнивание Z80 задано 4 байта.
- Прямые ASan/UBSan-тесты прошли 12 циклов и 120 кадров тестового ROM. Компьютерный менеджер проходит полный цикл выбора / смены ядра, 42 старых Python-теста проходят.
- ARMv5TE: `build/spmp_sms_armv5.o` — объединённый **перемещаемый ARM ELF32/EABI5** без исполняемого адреса, содержит примерно 93 КиБ кода, 110 КиБ инициализированных данных, 550 КиБ BSS. Этот объект пока имеет внешние импорты, поэтому **не запускается на консоли** без настоящего HAL, загрузчика и разрешения символов.

## Сборка и проверки в Linux

Нужны `gcc`, `make`, `clang`, `ld.lld`, `python3` (стандартная библиотека). В корне каталога:

```sh
make -j6 stage16-check
make sms-asan
make settings-preview
```

`stage16-check` включает регрессии Stage 15/10/9, SMS Plus GX (SMS и GG), менеджер настроек, ARMv5-сборку и хостовые тесты. Санитайзер запускается отдельно, потому что требует дополнительной компиляции исходников с инструментированием.

Демонстрационный кадр экрана настроек: `build/stage16-settings.png`.

## Что НЕ готово

1. Подтверждение аппаратного Power, настоящих регистров кнопок и схемы RAM Defender.
2. Загрузка/релокации ARMv5 полного SMS-модуля на физической консоли, D/I cache, резидентность и выгрузка.
3. Сохранения состояний SMS; настройки изображения/frameskip/специфичные параметры ещё не применяются в каждом конкретном ядре.
4. Проверка совместимости на реальных игровых ROM и измерение FPS на аппаратном CPU; тесты выполнялись только на специально созданных ROM на ПК.
5. Порты Mega Drive / SNES / GBA / ZX и другие платформы из дорожной карты; этим ядрам ещё нужны отдельные адаптеры.

## Происхождение и лицензии

- `third_party/smsplus`: исходники SMS Plus GX / Retro-Go (см. `third_party/smsplus/LICENSE` и заголовки файлов).
- `third_party/fceumm`, `third_party/z26`, `third_party/tgemu`, `third_party/gambatte`: оригинальные лицензионные уведомления сохранены в исходных каталогах.
- Архив не включает коммерческие ROM, BIOS или закрытые файлы штатной прошивки Defender.
