# Итоги исследования штатных эмуляторов

Проанализирован каталог `IMAGE/GAME` из пользовательского образа `mmm-firmware-v3_FSP.img`. Найдены семь уникальных ARM-бинарников для пяти платформ: NES, GB/GBC, GBA (три варианта), SNES, Mega Drive. Размеры и SHA-256 хранятся в `stock_emulators.json`.

Важно: бинарники начинаются с ARM-кода, а не с заголовка обычного ELF или `NGame1.0`. Они не являются автоматически совместимыми с нашим новым интерфейсом. Совместимость и текущий набор мапперов штатного NES/SNES невозможно достоверно определить лишь по размерам и строкам; необходимы тестовые ROM и сравнение поведения на железе. Не следует обещать прирост совместимости только потому, что выбрана новая кодовая база.

Ни один из файлов `.BIN`, BIOS или полный заводской FSP-образ не менялись и не входят в пакет Stage 4. Цель каталога замен — построить собственную SPMP-OS с новым набором cores, а не подменять ARM-код на том же адресе в оригинальном модуле.

**Следующий измеримый шаг:** статически связать FCEUmm и Gambatte с host HAL, после чего адаптировать ARMv5 и тестировать ROM без обмена с RedBoot. Для GBA наиболее рискованна архитектура dynarec; ARMv6-бэкенд не совместим с ARMv5.
