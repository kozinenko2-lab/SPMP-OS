# SPMP-OS Stage 9 — Gambatte и модель резидентного ядра

**Назначение:** исходный исследовательский проект SPMP-OS для Defender MultiMix Magic (SPMP8000), основанный на Stage 8 и шести новых архивах пользователя.

**Это НЕ IMG для установки на консоль. Не прошивать RedBoot/NAND данным пакетом.**
Аппаратный загрузчик ARM926EJ-S, драйверы дисплея/кнопок/звука/SD и загрузка переносимых модулей на реальном Defender **не проверены**.

## Выполнено и реально протестировано

- Интегрировано **полное исходное дерево Gambatte**, GPLv2, в `third_party/gambatte`.
- Gambatte собирается штатным Makefile проекта в `gambatte_libretro.so` и **загружается на Linux по требованию**, не линкуется в общий хост-исполняемый файл.
- `src/cores/gambatte_adapter.c`: libretro callbacks для RGB565 160×144, stereo PCM, управления и battery SRAM; RAM RTC обрабатывается отдельно (`gb-rtc`).
- Реальный цикл эмуляции GB/GBC проверен на **двух собственных 32-КиБ ROM** с валидным заголовком и кодом LR35902: запись в SRAM, настройка LCD/VRAM, программная шахматная плитка, кадры и звук.
- Применён принцип **одного активного ядра** в `src/cores/registry.c`:
  * пауза/возврат в меню сохраняет исполняемый ROM и состояние процессора;
  * повторный вход в ту же игру просто снимает паузу;
  * смена ROM на том же ядре выгружает старую игру, сохраняет SRAM и оставляет код ядра в RAM;
  * смена ядра загружает новый модуль; Linux-версия Gambatte физически выгружается через `dlclose()`;
  * `spmp_core_shutdown()` полностью закрывает активное ядро и освобождает его код, если он был динамическим.
- При загрузке Gambatte первоначально выделяется ROM-буфер 32 КиБ и расширяется при необходимости до 8 МиБ. Это **не доказательство** достаточной памяти на Defender для крупных картриджей.
- Регрессии: `make host test-cores`, `python3 -m unittest discover -s tests -v` → **42 теста успешно**; `build/gambatte_harness` проверяет загрузки/выгрузки 2/2.
- Никакие оригинальные системные бинарники, RedBoot и FSP пользователя не модифицированы.

## Чего пока нет

- Загружаемый ARMv5 ELF-модуль Gambatte (потребуется рабочая ARM EABI C++ стандартная библиотека/sysroot и модульный загрузчик с релокациями).
- Поддержка передачи управления от RedBoot/eCos к независимой SPMP-OS на настоящей консоли.
- Физическая выгрузка **всех** старых ядер: FCEUmm, z26, TGEmu и CHIP-8 в текущей Linux-хост-сборке ещё статически связаны. Менеджер отслеживает резидентность логически; на практике `dlopen`/`dlclose` реализованы **только для Gambatte**. При полной SPMP-OS на устройстве все ядра должны быть отдельными модулями ROMFS/Flash.
- Сборка SNES, MesenCE, LCD и Retro-Go в исполняемые ядра этой версии. Их исходники проанализированы и оценены в `SOURCES_AUDIT.csv`; они не обозначаются работающими.

## Сборка и тесты из корня проекта (ПК Linux)

```sh
make -j8 gambatte-host host test-cores
python3 tests/generate_gambatte_roms.py
python3 -m unittest discover -s tests -v
./build/spmp-os-host --cores
./build/spmp-os-host --run-core gb --content samples/spmp_battery.gb --frames 10 --screenshot build/gambatte-preview.ppm
./build/gambatte_harness
```

Gambatte компилируется с Linux `g++`; остальные части — со штатным C toolchain. Для Android или Windows хост-пути пока отсутствуют. Для дальнейшей ARMv5-портации нужен toolchain **armv5te / ARM926EJ-S / soft-float**, не ARMHF для ARMv7.

## Следующие переносы

1. **Gambatte на ARMv5:** собрать весь код C++ без Linux, привязать к аппаратному HAL и загрузчику модулей; проверить фактическую память и скорость.
2. **SNES:** оценить предоставленный Snes9x как эталон; собрать компактный Snes9x 2005/2002 или обрезанный современный профиль, проверить звук и RAM.
3. **Retro-Go:** перенести SMSPlusGX для Master System/Game Gear, Handy для Lynx, при необходимости Gnuboy как малозатратную альтернативу Gambatte.
4. **Mega Drive:** PicoDrive, отдельно GBA (gpSP / ARMv5 JIT), прочие ранее предоставленные эмуляторы.
5. Когда стабилизируются эмуляторы — Space Cadet, EDuke32 и мультимедиа.

## Лицензии

`third_party/gambatte` и FCEUmm — GPLv2; MesenCE и LCD Game Emulator — GPLv3, поэтому нельзя без анализа совместимости просто склеить их GPLv3-исходники с GPLv2-only движками. Современный Snes9x имеет отдельное лицензирование, включая ограничения на коммерческое использование. При распространении готового образа нужно соблюдать лицензии каждой включённой части. Все исходники Gambatte сохранены с исходными заголовками. Тестовые GB/GBC картриджи написаны для тестирования, коммерческих ROM нет.
