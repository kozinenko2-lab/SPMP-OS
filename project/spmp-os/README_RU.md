# SPMP-OS Stage 19 — PicoDrive / Sega Mega Drive

**Назначение:** полный исследовательский комплект SPMP-OS с интегрированным ядром PicoDrive из `picodrive-master.zip` пользователя. **Это не прошивка, не FSP IMG и не готовый ARMv5 модуль для реальной консоли Defender.** RedBoot и исходная прошивка не изменялись.

## Проверенный результат

- Настоящий PicoDrive (Motorola 68000: FAME, Z80: CZ80, VDP, YM2612, SN76496) собран в Libretro `.so` для x86-64 Linux из включённых исходников.
- PicoDrive подключён к общему диспетчеру SPMP-OS и его файловому API: ядро стартует синтетический Mega Drive ROM, выводит 320x224 и генерирует звук.
- Программа для Motorola 68000 выполняет `MOVE.B #$5A,$00FF0000`; результат считывается из эмулируемой RAM и проверяется. Проверены 19 кадров с повторным запуском игры, пауза, сохранение/восстановление состояния.
- Проверена работа на синтетических `.md` и `.smd` картриджах без коммерческих данных.
- Код Mega Drive регистрируется `HOST_TESTED` и имеет предварительную проверку наличия/размера ROM перед выгрузкой текущей игры.
- ARMv5TE/soft-float: отдельно собраны настоящие C-модули FAME, CZ80, видеовывода и звука; единый **неполный** перемещаемый объект содержит неразрешённые символы и не может запускаться как standalone эмулятор.
- Автоматический прогон Stage 19: `make stage19-check`; 54 регрессионных Python теста + самостоятельные программы проверок из Makefile.

## Сборка и воспроизведение

Требуются Linux x86-64, gcc/g++, GNU make, Python 3, Clang/LLVM с `--target=armv5te-none-eabi`, lld, `readelf` и стандартные библиотеки разработки. Часть сборочных команд может использовать Clang/LLVM из вашей системы.

```sh
make stage19-check
```

Частичные задачи:

```sh
make stage19-picodrive     # Собрать настоящую Libretro библиотеку PicoDrive для Linux ПК
make stage19-md-test       # Проверка M68K, кадров, аудио, save-state, загрузки другого ROM
make stage19-demo          # Вывод тестового кадра из Mega Drive
make stage19-arm-md        # Только частичный ARMv5 ELF32 ET_REL: NOT EXECUTABLE
```

Пакет содержит готовые диагностические ROM в `samples/`, исходники PicoDrive в `third_party/picodrive/`, основной код SPMP-OS в `src/`, интеграцию в `src/cores/libretro_multi_adapter.c`, тесты `tests/stage19_megadrive_harness.c` и `tests/test_stage19.py`, а также `firmware/module_catalog.json` со статусом `firmware_flashable: false`.

## Ограничения

- Исходный ZIP PicoDrive не включал Git-подмодули `libpicofe`, `Cyclone`, `libchdr`, `emu2413`, `dr_libs`. В этом профиле используются FAME/CZ80 и минимальная замена заголовка PicoFE. Sega CD MP3/CHD и YM2413 Master System отключены; SMS/GG обрабатывается отдельным SMSPlusGX ядром.
- Вариант 32X и Sega CD не тестировался и не считается поддерживаемым.
- Это **сборка для ПК**; полный ARMv5 PicoDrive, аппаратные LCD/аудио/кнопки, карта RAM, аппаратная кнопка Power и реальная производительность на Defender не проверены. Linux `.so` не загружается в независимую ARMv5 SPMP-OS.
- Состояния игрового меню и превью работают в хостовом SPMP-OS при поддержке ядром сериализации; формат и надёжность работы на физической консоли требуют отдельного тестирования.
- PSX4ALL по-прежнему только экспериментальный ARMv5 ET_REL с неразрешёнными символами. **Не прошивать эти файлы в устройство.**

## Правовые условия

PicoDrive (`third_party/picodrive/COPYING`) разрешает некоммерческое распространение при сохранении уведомлений и предоставлении исходного кода модифицированной версии. Присутствуют и другие лицензии сторонних проектов, которые необходимо учитывать перед распространением. Коммерческие ROM не включены.

См. подробности в `docs/STAGE19_RU.md`. Прошлая информация сохранена в `STAGE18_README_RU.md`.

## Stage 27
Под ARMv5 собраны 15 базовых исходных компонентов gpSP (CPU ARM7TDMI, GBA RAM/VRAM, звук, Libretro и сохранения), плюс встроенный открытый BIOS и bounded-heap-адаптер. После частичного связывания остаются 42 внешних зависимости. Подробнее: `README_STAGE27_RU.md`; `make stage27-check`.
