# Объединение Audio v6 с игровой веткой

Для каждой ветки сохраните отдельный исходный архив. **НЕ** накладывайте собранную копию Stage10 как целый проект поверх игровой сборки.

Патч v6 содержит только новые пути `features/multimedia/audio_v6/**`. Никакие файлы `src/cores`, `src/loader`, `RedBoot`, `Flash`, `third_party` не изменяются. Изменения фиксируются в `.spmp-patches/spmp-mm-audio-v6.json` и сверяются по SHA-256.

```sh
python3 tools/mm_audio_v6_patch.py --target /path/to/SPMP-OS --check
python3 tools/mm_audio_v6_patch.py --target /path/to/SPMP-OS --apply
python3 tools/mm_audio_v6_patch.py --target /path/to/SPMP-OS --verify
python3 tools/mm_audio_v6_patch.py --target /path/to/SPMP-OS --remove
```

Устанавливайте рядом с `CodecLab v3`, `MP3 Player v4`, `Audio v5` в любом порядке; включение их в итоговую программу требует отдельных опций линковщика. Пока у Stage10 нет общей динамической загрузки мультимедийных модулей на реальном железе, поэтому установка **исходного патча** не означает автоматического добавления пункта WMA/AMR в системное меню.

Если файлы установленного патча были изменены, удаление блокируется. При коллизии путей установка отказывается заменять файлы. Изменённый игровой код сохраняется нетронутым при установке и удалении. Перед слиянием двух веток рекомендуется сделать резервную копию дерева и запустить тесты сборки и контроллерного интерфейса.
