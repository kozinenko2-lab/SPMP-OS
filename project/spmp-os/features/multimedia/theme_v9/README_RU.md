# SPMP-OS Multimedia Themes v9 — 34 темы (25 предыдущих + 9 новых)

**Формат дисплея:** 320×240, RGB565 little-endian. **Целевая архитектура:** ARMv5TE / ARM926EJ-S, freestanding EABI5 soft-float. **Статус:** исходники, ресурсы и интеграция в тестовый Stage10; НЕ образ для прошивки NAND/RedBoot/Flash. Работа на физической консоли не подтверждена до подключения аппаратных LCD/SD/FAT/RTC/звукового HAL.

## Что сделано

В этой версии **34 темы**: все **25 существовавших v8** (исходные файлы `themes/<id>/*` сохранены побайтово) и 9 новых по последним согласованным изображениям:

| ID | Русское название | Группа |
|---|---|---|
| `action_heat_90s` | Огненный город 90-х | Боевики |
| `neon_pursuit_90s` | Неоновая погоня 90-х | Боевики |
| `urban_strike_90s` | Городской удар 90-х | Боевики |
| `beach_glow` | Пляжное сияние | Девушки |
| `velvet_pulse` | Бархатный пульс | Девушки |
| `runway_shine` | Звезда подиума | Девушки |
| `circuit_storm` | Гоночный шторм | Автомобили |
| `ocean_curve` | Океанский серпантин | Автомобили |
| `gallery_velocity` | Галерея скорости | Автомобили |

**Не перепутать**: презентационные изображения с уже нарисованными буквами не используются как готовый экран. Из них извлечены области **без меню и статусных надписей**, обрезаны и конвертированы в отдельные 320×240 `background.png` + `background.spbg`. Это не полностью новое изображение с дорисованными отсутствующими частями — кадрирование может скрыть часть оригинальной сцены.

## Файлы каждой темы

- `background.png`: чистый 320×240 RGB фон для редактирования.
- `background.spbg`: 16 байт заголовка `SPBG` + 153600 байт RGB565, CRC32; подходит для потокового чтения с SD.
- `style.spth`: 32-байтовый бинарный стиль, 6 цветов RGB565, флаги.
- `theme.json`: ID, название, палитра, источник и SHA256 изображения, параметры.
- `ui_list_panels.png`, `ui_grid_panels.png`: раздельные прозрачные RGBA 320×240 панели **без текста и иконок**.

Общие иконки без букв: `themes/shared/icons.spi` (8 символов 18×18) и `themes/shared/icons/*.png`. RU/EN названия генерирует движок в момент отрисовки по языку меню. Звуки навигации/выбора/назад находятся в `themes/shared/sounds/` (WAV), подсветка выбранного пункта анимируется в C-движке. Строка статуса показывает только **часы, уровень громкости, присутствие SD-карты**: нет Wi-Fi, нет батареи. Без RTC время `--:--`; без SD — иконка отсутствия карты. Поддержка пользовательского языка потребует соответствующего шрифта для других письменностей.

## Сборка и тестирование на ПК

```sh
cd SPMP-OS_Themes_v9
sh tools/build.sh
sh tests/run.sh
# После этого: previews/ALL_THEMES_320x240.png и previews/<id>_{list,grid}.png
./build/theme_preview_host themes beach_glow list /tmp/beach.ppm
./build/theme_preview_host themes circuit_storm grid /tmp/race.ppm
./build/theme_preview_host themes runway_shine list /tmp/runway_en.ppm 1 1 65 full en
python3 tools/select_theme.py gallery_velocity --layout grid --output config/selected_theme.sptc
```

ARMv5 библиотека: `build/libspmp_ui_themes_v9_armv5.a`; API `spmp_ui_theme_v7.h` сохранён, каталог и конфиг имеют v9-префикс (`spmp_theme_catalog_v9.h`, `spmp_theme_config_v9.h`). Конфиг SPTC: 40 байт CRC32. Сама прошивка должна читать/сохранять его через файловый HAL.

## Установка независимого патча в Stage10 (и будущую игровую ветку)

Распаковать полный архив в отдельную папку. Установить из этой папки (заменить `/path/to/...` своим расположением исходников):

```sh
python3 tools/theme_patch.py install /path/to/SPMP-OS_Stage10
python3 tools/theme_patch.py verify /path/to/SPMP-OS_Stage10
# Удалить отдельную v9, НЕ трогая v8 и игровые файлы:
python3 tools/theme_patch.py uninstall /path/to/SPMP-OS_Stage10
```

Файлы v9 устанавливаются **только** в `features/multimedia/theme_v9/`, манифест — `.spmp_theme_v9_manifest.json`. Патч не перезаписывает старые файлы, считает SHA256 каждого файла и запрещает удалять изменённые пользователем файлы. Старые `theme_v7` и `theme_v8` могут сохраняться. Новая v9 уже **содержит все 34 темы**, то есть v8 не требуется для неё отдельно.

**Важно:** нельзя одновременно привязывать v8 и v9 реализацию одних и тех же базовых функций рендера к одному исполняемому файлу; активной в финальной прошивке должна быть только одна версия движка. Наличие обеих папок на SD/в дереве исходников не является конфликтом.

### Необязательный тестовый хук Stage10

```sh
python3 features/multimedia/theme_v9/tools/stage10_host_hook.py . --check
python3 features/multimedia/theme_v9/tools/stage10_host_hook.py .
make host
./build/spmp-os-host --theme-v9-preview features/multimedia/theme_v9/themes beach_glow list /tmp/beach.ppm
python3 features/multimedia/theme_v9/tools/stage10_host_hook.py . --uninstall
```

Он изменяет только `src/host/main.c` и `Makefile` с резервной копией и проверкой конфликтов, чтобы проверить одну и ту же C-отрисовку через тестовый `spmp-os-host`. **Если v7/v8 host-хук уже установлен, сначала откатить его** — никакой автоматической замены кода игровой ветки.

## Результаты проверок

- 34 × 2 = 68 реальных экрана из C-движка; каждое RGBA / RGB565-изображение 320×240.
- Тесты русских/английских подписей, отсутствующей SD-карты, тестовые 30 ситуаций рендера v7, работа HAL мостика.
- ARMv5TE freestanding компиляция, проверка таблицы каталога 34 элементов, CRC32 SPTC.
- Тестовая установка v8 + v9 рядом; новая C-тема выведена через собранный `spmp-os-host`; откат v9 сохранил v8 и правку в игровом исходнике.
- Запись на реальную консоль, тест производительности и работа физического DAC/LCD/RTC/SD **не проводились**.

## Лицензии/распространение

Сборка содержит изображения по последним согласованным концептам чата. В них могут быть стилизованные элементы, напоминающие автомобили, персонажей или логотипы; для публичной публикации проверить права на реальные изображения, персонажей и товарные знаки. Уведомление о сторонних лицензиях на шрифтовые данные: `docs/DEJAVU_LICENSE_NOTICE.txt`. Оригинальные бинарники FSP/NAND в пакет не входят.
