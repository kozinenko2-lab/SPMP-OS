# SPMP-OS Audio v5 — интерфейс внедрения на реальном SPMP8000

## Необходимые аппаратные работы

1. Реализовать SD/FAT `read/seek/size` с корректными короткими чтениями и возвратом ошибок. Нулевое значение `read` означает EOF.
2. Выделить отдельный heap для Tremor; выполнить замеры peak usage на реальном устройстве. Нельзя выделять PCM, сжатый поток и экран в одном слоте эмулятора без проверки карты RAM.
3. Реализовать фактические `audio_open`, `audio_write_s16`, `audio_close` в штатном Stage10 HAL (DMA/I2S/DAC). `spmp_audio_stage10.c` связывает только вызовы, регистровый код не добавлен.
4. При включённой фоновой музыке согласовать владение DAC между эмулятором и плеером в одном аудиомикшере с очередью/блокировкой. Пока нет аппаратного теста, включать одновременно оба клиента нельзя.
5. Для AMR: собрать OpenCORE NB/WB для ARMv5 EABI5, soft-float; измерить энергопотребление и загрузку CPU. Для WMA: реализовать отдельный декодер/provider, не связывая закрытые стоковые EABI объекты вслепую.
6. Испытать PCM тестами, затем продолжительностью 30+ минут на конкретной плате, включая переход в меню и выход без застревания DMA.

## ABI и память

ARMv5 цель: `--target=armv5te-none-eabi -mfloat-abi=soft`. Не путать с пересобранными оригинальными `LIB*.O` старой FSP; их соглашения, вызовы и память пока не доказаны совместимыми. Динамическое подключение `*.a` невозможно: библиотеки статически линкуются при создании исполняемого overlay.

Требуемый freestanding C API указан в `freestanding/include`. Он содержит **заголовки-прототипы**, но не гарантирует реализацию функций. Связка должна обеспечить ARM EABI helper symbols (`__aeabi_*`), allocator, C string functions и при использовании Tremor `stdio` convenience helpers либо собирать только callback-путь с garbage collection of unused sections.

Рекомендуемый pipeline: SD chunk → decoder → PCM16 scratch → audio HAL PCM ringbuffer → DMA → DAC. Повторное копирование PCM по возможности исключить; не блокировать игровой IRQ. Схемы реального видеоплеера, FM-тюнера и цветовых тем оставлены в отдельных ветках.
