# SPMP-OS File Manager FM-04 — экранная клавиатура

**Цель:** ARM926EJ-S / ARMv5TE, экран 320×240 RGB565, независимая ветка файлового менеджера. **Это исходники и ARMv5 EABI5-объект для интеграции, не образ для Flash.**

## Реализовано

- Три раскладки: русская (все 33 буквы, включая `ё` и `ъ`), английская, цифры и символы.
- Shift, смена языка и символов, пробел, курсор влево/вправо, Backspace, Delete, очистка ввода, OK, отмена.
- UTF-8 без разрыва многобайтовых символов; предел 255 байт, соответствующий `FM01_NAME_MAX` (максимум может быть меньше для VFAT в зависимости от кодировки FAT backend).
- Фильтрация небезопасных имён для FAT: управляющие символы, `/\\:*?\"<>|`, завершающие пробелы и точки, псевдопапки `.`, `..`, зарезервированные DOS-имена.
- Вызов из состояния `FM02_RENAME_INPUT_REQUIRED` через `fm04_open_rename()`, сохранение через `fm04_finish()` / `fm02_supply_rename()`, отмена без переименования.
- Экран 320×240. Рендерер пишет в переданный RGB565-фреймбуфер и рисует все строки через `fm01_font.draw` — системный шрифт, никаких встроенных растровых подписей.
- Переводы можно задавать через `fm04_set_translation()`; примеры RU/EN используются как запасной вариант, а третьи языки подключаются через таблицы системной локализации.
- Темы v9: использует цвета `fm01_palette`, не перезаписывает изображения и звуки.
- Freestanding ARMv5, без heap/libc внутри FM-04 и без Linux-вызовов. Для запуска на Defender нужен реальный HAL кнопок, LCD/SD и файловый backend.

## Управление

| Кнопка | Действие |
|---|---|
| Крестовина | Перейти к соседней клавише |
| A | Нажать выбранную клавишу |
| B | Удалить символ слева |
| Select | Переключить символы / буквы |
| Start | Подтвердить текст (переименовать) |
| Select + B | Отмена без изменений |

В нижней строке клавиатуры доступны отдельные кнопки **ЯЗ**, **#+**, **ПР**, **<**, **>**, **BS**, **DEL**, **CLR**, **ОТМ**, **OK** и **Рг**. Системная локализация может заменить эти подписи.

## Сборка и проверка

Установите поверх исходников SPMP-OS с FM-01, FM-02 и FM-03:

```sh
python3 install.py /path/to/SPMP-OS
python3 install.py /path/to/SPMP-OS --verify
cd /path/to/SPMP-OS/features/filemanager/FM04
sh tools/build.sh
python3 tools/preview.py
python3 /path/to/FM04-patch/install.py /path/to/SPMP-OS --uninstall
```

`tools/build.sh` запускает модульные тесты, 120000 случайных операций редактирования, AddressSanitizer/UBSan, полноценное переименование UTF-8 файла на POSIX и объединённую ARMv5-компоновку FM-01..FM-04. `tools/preview.py` рендерит четыре экрана в действующих темах; для демонстрации нужен Pillow и NumPy, для прошивки — нет.

## Известные ограничения

1. Реальный FAT-драйвер Defender, аппаратный дисплей и ввод кнопок не испытывались; только ПК и ARMv5 cross-compile.
2. Текущий интерфейс системного шрифта FM-01 предоставляет *draw*, но не *measure*. Поэтому положение вертикального курсора в длинной строке рассчитывается приблизительно по символам. Точная ширина для пропорциональных шрифтов — дополнительный API в будущей версии.
3. В существующем POSIX-адаптере FM-01 замечено повторное чтение корня каталога через `dup(rootfd)` (общая позиция директорий), иногда мешающее рефрешу. FM-04 исходник FM-01 не меняет; в тесте используется вложенный каталог. Аппаратный FAT backend должен создавать новый независимый дескриптор чтения.
4. Подключение аппаратной клавиатуры непосредственно в `spmp-os-host` не выполнено: FM-04 предоставляет `fm04_buttons()`/`fm04_render_overlay()`, UI-контроллер должен передавать кнопки в модальный редактор перед FM-02.
5. Пока это однострочный ввод для переименования и коротких полей. Многострочный текстовый редактор — FM-05.

**Игровые исходники, прошивка/RedBoot, коллекция из 34 тем, FM-01/02/03 не перезаписываются.**
