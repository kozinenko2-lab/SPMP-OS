# FM-04 — отчёт тестирования

- Модульные тесты UTF-8: кириллица, символы Unicode из четырёх байт, передвижение курсора, вставка, удаление, попытки некорректной последовательности UTF-8.
- 120 000 псевдослучайных операций редактирования с проверкой UTF-8-инвариантов.
- Конфликты FAT: точки, слеши, обратный слеш, запрещённые символы, DOS-имена, хвостовые пробелы и точки.
- Реальная операция переименования файла с кириллицей через существующие FM01 POSIX и FM02 action backend.
- AddressSanitizer/UndefinedBehaviorSanitizer: модульный тест завершён без сообщений о нарушениях.
- ARMv5TE ARM926EJ-S soft-float, freestanding EABI5: объединённый `FM01_to_FM04_combined_armv5.o`, `nm -u` пуст.
- Рендеринг 4 реальных экранов 320×240 с цветами Themes v9, текст через внешний системный шрифтовой callback.

Ограничение: нет аппаратного теста на Defender; тестовый POSIX-драйвер не является FAT-драйвером SD.
