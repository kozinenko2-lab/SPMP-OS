# FM-05 — инженерные испытания

Данные получены на ПК Linux и кросс-компиляцией Clang/LLVM для ARMv5TE (ARM926EJ-S). **Исполнение кода на Defender пока не проверялось.**

| Тест | Результат |
|---|---|
| Файл UTF-8 с кириллицей и CRLF | PASS; переносы сохраняются |
| Редактирование, вставка/удаление UTF-8 | PASS |
| Вертикальное и горизонтальное перемещение курсора | PASS |
| Поиск и Undo последнего изменения | PASS |
| FM-04 клавиатура: ввод текста и запрос поиска | PASS |
| Кнопочный контроллер FM-05 | PASS |
| Файлы из реальных POSIX-каталогов | PASS |
| Конфликт версии файла / подмена symlink / traversal `..` | PASS — отказ в записи |
| Слишком большой документ / неверный UTF-8 | PASS — без обрезания и сохранения |
| Прерывание сохранения до замены | Исходный файл сохраняется (модель временной записи) |
| 40 000 случайных UTF-8 правок | PASS, сохранена валидность буфера |
| ASan/UBSan для ядра и POSIX | PASS |
| Общая компоновка FM01–FM05 ARMv5TE, EABI5 | PASS, нет undefined symbols |
| Реальный дисплей/SD Defender | НЕ ПРОВЕРЕНО |

Системная память: `sizeof(fm05_doc)=33768` байт, `sizeof(fm05_session)=34072` байта, кроме внешнего RGB565-фреймбуфера. Ограничение документа 32768 байт.

**Известное ограничение консистентности:** в POSIX backend два последовательных шага проверки ревизии + `renameat`, между ними остаётся окно гонки от некооперирующего внешнего писателя. Для поддерживаемого FAT backend требуется дополнительная транзакционная модель или эксклюзивное управление записью со стороны ОС.
