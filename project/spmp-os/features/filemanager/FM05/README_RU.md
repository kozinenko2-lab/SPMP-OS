# SPMP-OS File Manager FM-05 — текстовый редактор

**Статус:** независимый исходный модуль и ARMv5 EABI5-библиотека. Реальные файлы редактируются на ПК через безопасный POSIX backend. На Defender потребуется рабочий FAT backend и подключение контроллера к системному меню. **Это не прошивка и не IMG для Flash.**

## Реализовано

- TXT, LOG, INI, CFG, XML, MD, CSV, JSON и SH (расширения сравниваются без учёта регистра).
- UTF-8 без разрыва многобайтовых символов, кириллица, редактирование строк и вставка переносов LF/CRLF.
- 320×240 RGB565, цветовая палитра от текущей темы; **шрифт и подписи берутся из системы** через `fm01_font.draw`, нет растрового текста, зашитого в иконки.
- Просмотр с вертикальной и горизонтальной прокруткой, номер строки/позиции, статус несохранённых изменений.
- Поиск текста (регистр учитывается), переход к следующему вхождению с возможностью поиска с начала.
- Ввод через уже существующую FM-04 экранную клавиатуру RU/EN/символы. Запрос ввода и поискового слова не требует новых шрифтов.
- Удаление символов, один шаг Undo для операций до 255 байт, отмена выхода с изменённым документом.
- Сохранение с контролем ревизии файла; POSIX backend пишет во временный файл в той же папке, синхронизирует и заменяет оригинал. При ошибке до замены оригинальный файл сохраняется. Проверки symlink и `../`.
- Программное состояние в собственных ~34 КБ RAM, без heap, libc или файловых вызовов в ARM5-ядре. Экранный буфер (320×240 RGB565) передаётся системой.
- `fm05_open_selected()` для открытия выделенного файла из FM-01; `fm05_session_buttons()` подключает клавиатуру FM-04 к редактору.

## Управление (контроллер сеанса)

| Кнопки | Действие |
|---|---|
| Крестовина | Влево/вправо по UTF-8, вверх/вниз между строками |
| A | Открыть FM-04 клавиатуру для вставки строки |
| Select | Поиск по документу через FM-04 |
| Start + A | Вставить новую строку |
| Start + Select | Сохранить |
| Start + вверх/вниз | Постраничная прокрутка |
| Start + влево/вправо | Начало/конец строки |
| B | Закрыть (с подтверждением при несохранённых изменениях) |
| Подтверждение: A / B | Отменить изменения / продолжить редактирование |

Внутри клавиатуры действуют её собственные кнопки: крестовина, A, B, Select, Start и Select+B (отмена ввода). Нужны **события нажатия**, а не непрерывно удерживаемые биты.

## Ограничения

1. **Максимальный документ — 32 768 байт.** Больший файл отвергается без обрезания. Ограничение фиксированного RAM; просмотр гигантских LOG требуется в отдельном потоковом режиме последующей версии.
2. Поддерживается UTF-8. Устаревшие ANSI/CP1251/UTF-16 файлы не конвертируются автоматически. При недопустимой кодировке оригинал не затрагивается.
3. Вставка из экранной клавиатуры выполняется строкой до 255 байт. Один шаг отмены (не история команд). Поиск чувствителен к регистру.
4. POSIX-адаптер с контролем ревизии защищает от уже обнаруженных внешних изменений, но проверка ревизии и `renameat` не атомарны по отношению к сторонним процессам, не использующим блокировки. Аппаратный FAT backend должен реализовать собственные безопасные семантики замены с учётом извлечения SD/ошибок питания.
5. Фактические кнопки/RTC/SD/DAC/LCD на консоли ещё не испытаны. Нет автоматического запуска редактора из основного меню; предоставлен контроллер `fm05_session` для интеграции с FM-01 и FM-02.
6. Текст отображается штатным системным `draw`; позиция курсора оценена по фиксированной ширине 7 пикселей, поэтому для пропорциональных шрифтов нужен будущий `font.measure`. Не все функции (например, Undo) назначены на отдельные кнопки, но доступны через API.

## Сборка и тесты

```sh
python3 install.py /path/to/SPMP-OS
python3 install.py /path/to/SPMP-OS --verify
cd /path/to/SPMP-OS/features/filemanager/FM05
sh tools/build.sh
python3 tools/preview.py
python3 /path/to/patch/install.py /path/to/SPMP-OS --uninstall
```

`tools/build.sh` проверяет реальное сохранение файлов на ПК, UTF-8/CRLF/поиск/Undo, 40 000 псевдослучайных операций, сценарии ошибок и конфликтов, AddressSanitizer/UBSan. Собирает `libspmp_fm05_armv5.a`, совместный ARM5-объект `FM01_to_FM05_combined_armv5.o` и тестовый host renderer.

## Как подключить к SPMP-OS

```c
/* Файловая система на устройстве должна подставить собственные обработчики. */
static fm05_session editor; /* СТАТИЧЕСКИ, не на ARM-стеке */
fm05_fs io = { fat_read_document, fat_atomic_write_document, fat_context };
fm05_session_init(&editor, io);
/* Из выделенного файла FM-01: */
fm05_open_selected(&editor.doc, &file_browser);
/* На событиях кнопок: */
fm05_session_buttons(&editor, pressed_edges);
/* На системном RGB565-кадре: */
fm05_session_render(&editor, framebuffer, 320, &current_theme_palette, &system_font);
```

Для сторонних языков зарегистрируйте `fm05_set_translation(&editor.doc,callback,context)`. Шрифтовые глифы всегда приходят через `fm01_font`; графика темы не требует локализации.

## Безопасность объединения

Установщик `install.py` добавляет файлы **только в `features/filemanager/FM05/`**, проверяет SHA-256 и отказывается удалять/заменять изменённые файлы. FM-01–04, эмуляторы, темы v9, RedBoot и исходный FSP не изменяются. Изменения в другой игровой ветке не затрагиваются. После FM-05 следующий этап FM-06 — производительность и оформление, FM-07 — аппаратный FAT/LCD.
