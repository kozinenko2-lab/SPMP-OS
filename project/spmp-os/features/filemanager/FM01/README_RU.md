# SPMP-OS File Manager — FM-01 (первый самостоятельный этап)

**Статус:** работающий двухпанельный просмотр файлов и папок (read-only). Проверен на ПК и собран как freestanding ARMv5 EABI5 ET_REL; аппаратная работа с FAT/SD и LCD на Defender **не проверена**. Это не образ прошивки.

## Реализовано

- **320×240, RGB565:** две панели по 156 пикселей, активная рамка, компактные строки, выделение, скроллбар, системный шрифт через `fm01_font_draw` (UTF-8, русский/английский).
- **Два независимых каталога/курсора:** крестовина вверх/вниз — движение, влево/вправо — активная панель; `A` — папка; `B` — родитель; `Select` — переключение панели. Возврат в папку сохраняет курсор родителя (до 16 уровней).
- **Ровно девять строк видимой страницы:** постраничная загрузка записей через API `fm01_list_page`; не нужно загружать весь каталог в модель. Папки выше файлов, стабильный порядок нужен от файлового драйвера.
- **Нижняя строка:** количество файлов и каталогов активной папки, размер выбранного файла, дата последнего изменения `ДД.ММ.ГГ`. Все вычисления проходят в C.
- **Статус:** только время (его предоставляет RTC/прошивка), громкость (0–100%) и наличие SD-карты; нет сетевых/батарейных значков.
- **34 темы совместимы по палитре:** RGB565-рендерер умеет работать как самостоятельно, так и как **оверлей поверх фонового RGB565**, без второго буфера кадра. Цвета подаются из текущей темы; host-демо читает `themes/.../theme.json` из Themes v9.
- **Безопасный POSIX backend для тестов:** файловые операции только чтение, `openat` + `O_NOFOLLOW`, запрет `..` и переходов по символическим ссылкам. Всё ограничено выбранным корнем.
- **ARMv5:** объект ядра и рендерера, статическая библиотека `build/libspmp_fm01_armv5.a`; нет зависимостей от Linux/POSIX или аппаратного FPU в этих C-модулях.

## Не включено в FM-01

Копирование, перемещение, удаление, переименование, свойства, клавиатура и текстовый редактор — следующие этапы FM-02..FM-05. Кнопка `Start` пока зарезервирована. Не следует воспринимать отсутствие действий с файлами как ошибку: этот этап строго проверяет навигацию и интерфейс.

## Сборка и тесты

```sh
cd features/filemanager/FM01
./tools/build.sh
python3 tests/test_posix.py
# требуется python + Pillow + numpy и архив Themes v9
python3 tools/preview.py /path/to/SPMP-OS_Stage10/features/multimedia/theme_v9/themes
./build/fm01_host --root /path/to/sdcard
```

В папке `previews/` есть **настоящие 320×240 скриншоты**, полученные C RGB565-рендерером с обратным вызовом системного шрифта ПК (DejaVu Sans), а не нарисованные макеты. Для устройства следует предоставить системную реализацию `fm01_font_draw` и драйвер `fm01_list_page` для FAT/SD.

**Память:** модель хранит не более 9 записей на панель, путь до 511 байт, имя до 255 байт UTF-8; сам framebuffer 153600 байт выделяет ОС. Host POSIX adapter использует память ПК для полной сортировки каталога, но ARM-код *не* содержит его — для консоли нужен FAT-поставщик стабильных отсортированных страниц.

## Независимый патч

Из корня архива:

```sh
python3 install.py /path/to/SPMP-OS_Stage10
python3 install.py /path/to/SPMP-OS_Stage10 --verify
python3 install.py /path/to/SPMP-OS_Stage10 --uninstall
```

Установка пишет **только** `features/filemanager/FM01/`, не изменяя Makefile, общий загрузчик, игровую ветку или 34 темы. При конфликте или пользовательских правках операция прекращается; установщик не удаляет изменённые файлы. Для объединения с новым StageXX используйте этот же пакет, без замены общего проекта.

## Архитектура

`include/spmp_fm01.h` — публичный API, `src/fm01_core.c` — модель двух панелей, `src/fm01_render.c` — RGB565-рендерер, `host/fm01_posix.c` — *только* настольный backend, `host/fm01_demo_bridge.c` — host UI bridge, `tests/` — проверки. Версия FM-01 самостоятельная, а не замена старых бинарников.
