# SPMP-OS Stage 21 — PicoDrive ARMv5 live-code profile

## Сделано

- Полная перекомпиляция 31 исходного C-файла PicoDrive в ARMv5TE / ARM926EJ-S, soft-float, freestanding.
- Функции и данные разнесены по секциям: `-ffunction-sections -fdata-sections`.
- Частичный linker garbage collection с явными корнями PicoInit/PicoFrame/PicoState/etc; неиспользуемые секции отсечены.
- Количество неразрешённых символов сократилось **127 → 103** (24 устранены за счёт отсечения недостижимого кода).
- Формируется машинный JSON-аудит зависимостей, классифицированных по runtime, сжатию, Sega CD/32X и платформенному HAL.
- Добавлены 6 тестов проверки типа ARM ELF, воспроизводимости отчёта и состояния связи.

## Ограничения

- 103 внешних символа остаются, в том числе 31 в категории связанных с CD/32X (часть имён охватывает общие подсистемы).
- Это перемещаемый ARM-объект, **не исполняемый образ и не готовый модуль ядра**.
- Не применялись фиктивные пустые реализации GPU/CD/32X.
- Для устранения оставшихся ссылок потребуются условная компиляция соответствующих ветвей оригинального PicoDrive, реальный системный runtime и HAL; простой `NO_32X` недостаточен.
- Проверок на консоли Defender и замеров FPS не было.
