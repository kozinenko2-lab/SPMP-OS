# SD-карта для экспериментальных логов SPMP-OS

Файловая система: FAT32 или FAT16; указывать размер/схему раздела не нужно, пока драйвер не подтверждён.

```
/ (FAT32)
  SPMPOS/
    BOOT.PKG        # Stage42 экспериментальный пакет (не является прошивкой)
    LOGS/
      12345678.LOG  # 8.3 имя, ID сеанса определяет MMI
      A0B0C0D0.LOG
```

Папку `SPMPOS/LOGS/` создавать вручную (на ПК); текущий runtime не реализует mkdir. Путь логов записывает **только OEM MMI файловый backend после успешного FAT mount**, а RedBoot в актуальном коде работает только с read-only sector callback. При извлечении SD с включённым устройством возможна потеря последней пачки сообщений; вызовы `sync()` и `close()` обязательны после экспорта. Журнал и пакет BOOT.PKG являются независимыми файлами, ошибки логирования не должны влиять на выбор заводской прошивки.
