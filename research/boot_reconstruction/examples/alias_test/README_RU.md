# SPMP ALIAS TEST — пакет для Defender Multi Mix Magic

`SPMP_ALIAS_TEST.bin` — короткий диагностический NGame-пакет для штатной
`8000_MMI.RAP`. Он проверяет, что собственный контрольный блок приложения,
загруженный ниже `0x10000000`, читается по адресу `address | 0x10000000`.

Тест только читает RAM. Он не обращается к Flash, RedBoot, MMIO или CEVA, не
изменяет таблицы MMU и не запускает кодеки. Это проверка обнаруженного Stage58
uncached/unbuffered alias, а не проверка аппаратного кодировщика.

## Запуск

1. Скопировать `SPMP_ALIAS_TEST.bin` на карту памяти тем же способом, которым
   запускались предыдущие NGame-тесты.
2. Запустить файл и не нажимать кнопки. Примерно через несколько секунд
   приложение само вернётся в меню MMI.
3. Записать надписи `ALIAS READ PASS` или `ALIAS READ FAIL` и `SD LOG ...`.
4. Прислать файл `/fat20a0/hda0/SPMPALI.CSV` с карты и, по возможности,
   фотографию экрана.

Строка CSV содержит: версию, исходный адрес, alias-адрес, код результата,
маску несовпавших 32-битных слов и восемь прочитанных слов. Файл дополняется,
а не очищается, поэтому повторные запуски сохраняют историю.

Если на экране будет `SD LOG ERROR`, результат всё равно можно переписать с
экрана. При неожиданном зависании выключить и включить консоль обычным
способом: постоянная память тестом не изменяется.
