# Кандидатные профили кнопок отдельных устройств

`defender_multimix_magic_user_console_01.json` получен из пользовательского
SPMPKEYS.CSV. Это ручная метка одной консоли, не прочитанный аппаратный ID.
Коды относятся к cooked MMI GetKeys, не GPIO и не универсальной карте SPMP8000.

Записаны семь образцов: UP/DOWN/LEFT/RIGHT/A/B/START. Пользователь подтвердил,
что X/Y/L/R/SELECT/BACK присутствуют и нажимались по подсказкам, но API не дал
для них образцов. Громкость +/− также есть отдельно от L/R; в первой версии
теста подсказок для них не было. Нельзя заполнять эти восемь кодов догадками,
нулём или алиасами других кнопок.

Профиль неполный, `auto_apply=false`: действующая прошивка и управление SPMP-OS
им автоматически не изменяются. Следующий источник данных — состояния до
native cooked filter; подробности в [отчёте](../STAGE12_REPORT_RU.md).
