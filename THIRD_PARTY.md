# Сторонние компоненты

Исходники сторонних библиотек импортированы из предоставленного пользователем
архива, без предсобранных библиотек и объектных файлов. Их лицензии сохраняются
в исходных каталогах и имеют приоритет перед LICENSE-SPMP для этого кода.

| Компонент | Файл условий |
|---|---|
| FCEUmm | `project/spmp-os/third_party/fceumm/Copying` |
| Gambatte | `project/spmp-os/third_party/gambatte/COPYING` |
| gpSP | `project/spmp-os/third_party/gpsp/COPYING` |
| PicoDrive | `project/spmp-os/third_party/picodrive/COPYING` |
| SMS Plus | `project/spmp-os/third_party/smsplus/LICENSE` |
| Snes9x | `project/spmp-os/third_party/snes9x/LICENSE` |
| TGEmu | `project/spmp-os/third_party/tgemu/src/license` |
| z26 | `project/spmp-os/third_party/z26/copying.txt` |

Также сохранены уведомления в отдельных исходных файлах, вложенных библиотеках
и `project/spmp-os/research/`. Таблица не заменяет условия этих файлов.
Тестовые картриджи в `samples/` — небольшие диагностические примеры проекта;
генераторы MD/SMD и 32X сохранены в `tools/` проекта. Коммерческие ROM и BIOS,
оригинальные образы Defender и Ghidra-базы в этот импорт не включены.
