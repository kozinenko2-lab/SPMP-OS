# Задача для первого запуска Codex (можно скопировать целиком)

Проект SPMP-OS для Defender MultiMix Magic / Sunplus SPMP8000. Открой корень распакованной папки `SPMP-OS_Codex` и сначала прочитай `AGENTS.md`, `README_RU.md`, `docs/STATUS_ROADMAP_RU.md` и отчёты Stage53–55. Не менять оригиналы в `firmware/originals`, `firmware/unpacked_FSP`; никаких патчей RedBoot, записей NAND или подготовленных Flash-образов. Задача: выполнить Stage56 — восстановить точную последовательность запуска MMI/eCos/GUI и контракт перехода к запуску native-приложений. Используй 3 GZF пользователя и подготовленные ARM ELF, восстановленные карты потоков 35 entries, дизассемблирование и Ghidra Java-скрипты. Проверяй каждый адрес по оригинальному RAP SHA256 `5529b173b3fb612b2e7f516af807f1342d24ea6f7101be034e1e0d08fed25c4e`. Подготовь отчёт RU с именованными функциями, графом вызовов, ограничениями карты RAM, доказательствами ASM/Ghidra, гипотезами отдельно, автоматизированными тестами. Затем интегрируй уже установленный FM01–FM05 и Theme v9 в host/UI тестовое приложение `project/spmp-os` без аппаратного запуска. Запусти `make host`, `./build/spmp-os-host --cores` и тесты FM01..FM05. Если для работающей прошивки не хватает HAL, честно укажи блокер вместо утверждений о готовности. Следующий план — MMI logger и безопасная загрузка SPMP-OS через штатные механизмы, до изменения RedBoot.
